# The One Only Photography

A free, static photography website for GitHub Pages.

## Files

- `index.html` — all website content
- `style.css` — visual design
- `script.js` — mobile menu, photo lightbox, and current year
- `images/` — optimized photos

## Publish with GitHub Pages

1. Create a GitHub account at https://github.com/
2. Create a **public** repository named exactly:
   `YOUR-GITHUB-USERNAME.github.io`
3. Upload `index.html`, `style.css`, `script.js`, and the entire `images` folder.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then save.
7. Wait a few minutes and open:
   `https://YOUR-GITHUB-USERNAME.github.io/`

## Adding more photos

Put the new photo into `images/`, then copy a `<figure class="gallery-item">...</figure>` block from `index.html` and change its image filename and alt text.

For best loading speed, use JPG/WebP images around 2000–2500px on the long edge.
